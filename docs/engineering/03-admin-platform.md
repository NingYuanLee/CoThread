# 管理空间

管理空间地址为 `/admin`，沿用现有成员账号、密码和登录会话。未登录时使用现有登录页，登录后回到管理空间。所有成员都可在工作空间的个人设置中点击“进入管理空间”。每个成员账号默认可打开“我的工作”，以及账号权限下的“变更记录”“登录记录”；没有其他管理页面权限时，只能看到与自己相关的项目、迭代、任务和账号记录。

## 页面与功能

左侧为“我的工作 / 组织工作 / 账号权限 / 平台管理”菜单及第二级页面；右侧顶栏显示当前位置、当前成员和工作空间入口，内容区提供以下页面：

品牌与侧栏收缩控制复用工作空间组件，顶栏高度为 48px，图标按钮为 30px。内容区直接展示统一的 30px 筛选控件与表格，详情、新增、编辑及确认操作通过弹窗完成；弹窗复用工作空间的遮罩、关闭按钮和进入/退出动画。成员角色分配在成员列表弹窗完成，角色权限页仅维护角色与权限树，插件页通过下拉框切换 Agent 成员与插件类型。

| 页面     | 功能                                                                                                                                                                                    |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 我的项目 | 所有成员默认可打开。只列出本人已加入的项目，通过“详情 / 成员 / 记录”查看，不能新增、编辑或结项                                                                                          |
| 我的迭代 | 只列出本人已加入项目中的迭代，可按项目和状态筛选、分页，不能修改                                                                                                                        |
| 我的任务 | 只列出本人已加入项目中、与本人相关的任务（创建、来源、指派、承接或确认），可查看目标、约束、结果、状态和进度记录，不能修改                                                              |

| 项目管理 | 搜索与状态筛选、新增、结项、恢复，通过“详情 / 成员 / 记录”独立弹窗查看项目资料                                                                                                          |
| 迭代管理 | 跨项目查询、按项目和状态筛选、分页、修改进行中的迭代名称                                                                                                                                |
| 任务管理 | 跨项目查询、筛选、分页，查看目标、约束、结果、状态和进度记录                                                                                                                            |
| 账号管理 | 搜索、状态筛选、新增、停用、恢复、重置密码，展示头像，分配管理角色；通过“详情 / 项目”弹窗查看。本人或拥有对应“查看全部”权限时，行内“变更记录 / 登录记录”跳转到列表页并带上该成员用户 ID |

| 登录记录 | 所有成员默认可打开。服务端分页，含用户 ID 列和用户 ID 筛选。没有“查看全部”时只返回当前登录账号，并包含用该账号用户名或邮箱尝试但未匹配到用户的失败登录                                  |

任务执行、接受、转派和取消仍按原工作空间的流程操作。运行中和已结束的任务、已结项的项目与已归档的迭代无法通过管理空间修改资料。

插件配置仅有老翁、小祥两个成员对象。小祥和子 Agent 共用插件策略、工具清单与启用的自定义 Skills；历史子 Agent Skills 合并到小祥视图，新建和编辑统一保存到小祥配置。成员职责与任务归属仍由后端验证，工具共享不继承人类授权。

## 授权

权限目录在 `shared/admin-permissions.js`，结构为“菜单 → 页面 → 功能”。角色保存在 `admin_roles`，成员与角色的关联保存在 `admin_user_roles`，成员身份仍以 `users.id` 为准。

- “分配成员角色”功能归属成员管理页，沿用既有 `roles.assign` 权限键。分配选项接口按该功能鉴权，成员管理员无需获得角色管理页访问权限。
- 多角色权限取并集；功能权限自动包含所属页面与菜单。
- 只勾选页面时仅允许读取，不包含新增、编辑等功能；只勾选菜单不获得页面操作能力。
- 现有 `is_super_admin` 账号拥有全部权限，无需另建管理员或分配角色。
- “我的工作”不进入角色权限树，也不能被角色撤销。每个登录成员账号始终可以打开这三个页面，服务端只返回本人已加入的项目、这些项目的迭代，以及本人仍在项目内且与自己相关的任务。
- “变更记录”和“登录记录”对所有成员开放，页面权限不能被角色撤销。每个页面有独立的“查看全部”功能权限，默认不授予；没有该功能时，接口忽略其他成员的用户 ID 筛选，只返回当前登录账号。超级管理员拥有全部功能权限，因此可以查看全部。
- 普通成员默认没有组织工作、账号管理、角色权限和平台管理权限。超级管理员在“角色权限”中建立角色，再到“账号管理”分配角色后即可访问。
- 管理 API 每次请求都重新读取角色权限；撤销或变更授权后下一次请求立即生效。
- `/api/admin` 接口按 HTTP 方法与路径明确映射权限，未登记的管理接口默认拒绝访问。领域方法也校验相应权限。
- 委派管理员不能授予超出自身范围的权限，不能修改更高权限角色或成员的角色与账号，不能给自己修改角色。
- 超级管理员账号受保护，不能停用自己的账号或最后一位有效超级管理员。重置密码会使目标账号的现有登录失效。
- 角色修改、成员角色分配和迭代、任务资料修改记录在 `admin_change_logs`；项目、账号、Skill 的记录沿用原审计表。
- 「组织架构」在组织工作下，权限键为 `orgs`、`orgs.update`、`orgs.assign`、`orgs.link`。组织树的新增、改名、移动、归档写入 `org_change_logs`；人员归属写入 `account_change_logs`；项目主办和参与写入 `project_change_logs`。不记录正文或密钥。
- 一个人最多一个主组织。已有主组织时不能直接改到另一个组织，要先从原组织移出。一个项目最多一个主办，主办组织不能同时是参与方。仍有未归档下级的组织不能归档。已归档组织不能再被选为上级、主办、参与或新的人员归属。没有组织关联的项目仍可打开、发言和归档。组织不参与文档、迭代、任务和归档判断。

## 数据库迁移与验证

新增迁移 `100_admin_rbac.sql`。本地开发启动按既有流程自动迁移，其他环境按项目原有迁移/部署流程应用。迁移仅创建角色、关联和管理审计表，保留全部已有成员及超级管理员标记。

组织架构使用迁移 `120_organizations.sql`，新增 `organizations`、`org_members`、`project_org_links` 和 `org_change_logs`。不为已有项目或账号自动补组织。

模型配置使用迁移 `118_platform_model_settings.sql`，全平台一行。`GET /api/admin/model-settings` 要 `model-settings`，`PUT /api/admin/model-settings` 要 `model-settings.update`。保存携带 `expectedVersion`，冲突返回 409。审计只记地址、模型名、推理强度和密钥是否更新，不记密钥本身。

模型配置页 `/admin/model-settings` 将当前生效值和待保存表单分开展示，显示来源、版本、更新时间、老翁继承关系及环境变量的旧名回退。首次保存必须填写密钥；已有数据库配置时留空保留已保存密钥。保存成功清空密钥输入，供应商返回错误时保留当前版本与待修正表单。发生 409 时点击“重新读取”，基于最新版本重新修改。

每条候选路由依次校验普通 Responses、完整流式完成事件、老翁 JSON Schema 输出；单次最多 12 秒，每条路由总预算 36 秒。启用老翁覆盖时两条路由均需通过。校验只发送固定短提示，不带项目、成员或会话内容。密钥由现有凭据保险库加密，部署环境须长期保留 `CREDENTIAL_ENCRYPTION_KEY`；已有数据库配置无法读取或解密时明确停用，不退回环境变量。

运行中的任务及子任务保留捕获的旧模型。由于同一迭代的小祥与子任务共享运行时，切换后该迭代的新请求保持排队，等已有子任务结束才重建运行时并使用新模型；其他空闲迭代与新老翁工作可使用新配置。生效配置保存在进程内存快照中，模型调用不逐次查询配置表；启动、管理页读取或保存等控制路径负责加载。模型配置保存无需重启网站；服务重启后从数据库恢复。当前实现用于单个网站/执行器进程；若以后扩展为多个独立服务进程，需增加跨进程配置失效通知后再启用多副本写入。
