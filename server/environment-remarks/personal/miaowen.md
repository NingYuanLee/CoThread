# miaowen

腾讯广告妙问的 API KEY。它是个人环境变量，只属于当前登录账号。

问老翁关于腾讯广告、微信广告、朋友圈广告、视频号广告、开户、审核、素材、报表、诊断、创意或投放的问题时，共序会在调用妙问工具时注入这个值。模型不能直接读取它，也不会把它写进本机公共文件或对话。

## 如何获取

1. 打开 [妙问官网](https://miaowen.qq.com/) 并登录。
2. 在左侧进入「Skill 社区」。
3. 复制以 `sk-mw-` 开头的 API KEY。
4. 粘贴到这一行的 value 并保存。

钥匙失效时，回到妙问页面刷新后重新复制，再回来替换。不要把 KEY 发到对话里。
